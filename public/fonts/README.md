# Sticky-note handwriting fonts

Drop the two font files here with these exact names:

- `Hiragenda.ttf` — Hiragenda (English/Latin handwriting)
- `BurmeseHandwriting.ttf` — Burmese Handwriting Regular v1.000 (Myanmar)

They are referenced by `@font-face` rules in `src/app/globals.css`.
Until the files exist, sticky notes fall back to Kalam automatically.
